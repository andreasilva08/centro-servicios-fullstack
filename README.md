# Proyecto-Git - Sistema de Gestión de Reservas (Centro de Servicios)

## Descripción
Aplicación web Full Stack para administrar usuarios, servicios y reservas en un centro de servicios especializado.

## Tecnologías Utilizadas

* **Frontend:** Vue.js + Quasar Framework (HTML5, CSS3, JavaScript / ES Modules)[cite: 1]
* **Backend:** Node.js + Express.js[cite: 1]
* **Base de Datos:** MongoDB[cite: 1]
* **Control de Versiones & DevOps:** Git, GitHub, GitHub Projects, GitHub Actions (CI/CD)[cite: 1]

## Arquitectura del Sistema
